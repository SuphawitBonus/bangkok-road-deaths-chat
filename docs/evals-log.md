# บันทึกการปรับปรุงด้วยชุด dev

แต่ละรอบแก้ทีละอย่าง แล้วรันชุด dev ซ้ำ 3 รอบ (`--repeat 3`) เพราะผลของโมเดลไม่เหมือนกันทุกครั้ง
ตัวเลขทุกตัวในไฟล์นี้คือ **ค่าเฉลี่ย [ต่ำสุด–สูงสุด] จาก 3 รอบ** ของชุด dev 30 ข้อ
(1 ข้อ = 3.3 จุด ดังนั้นต่างกัน 1 ข้อในรอบเดียวยังไม่มีความหมาย)

กติกาที่ใช้ตัดสินว่า "การแก้ได้ผล": ค่าเฉลี่ยต้องดีขึ้น **และ** ไม่ทำให้ตัวชี้วัดคู่แย่ลง
(เช่นปฏิเสธถูกเพิ่มแต่ปฏิเสธผิดเพิ่มด้วย ไม่นับว่าดีขึ้น) ถ้าไม่ผ่าน ถอยกลับและจดไว้ว่าลองแล้วไม่ได้ผล

ตั้งค่าคงที่ทุกรอบ เว้นแต่ระบุว่าเป็นสิ่งที่แก้: `claude-haiku-5-5` · effort `medium` · max tool rounds 4

ห้ามดูผลรายข้อของชุด test ระหว่างนี้ (ดู [evals.md](evals.md) หัวข้อ "กติกาชุด test")
